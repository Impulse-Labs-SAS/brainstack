# Brand

The BrainStack logo: the **Pliegue** mark (one continuous line folded into three layers, ending in a node) and the wordmark in Geist SemiBold.

| File | Use |
|---|---|
| `brainstack-horizontal-dark.svg` / `-light.svg` | Main logo, for dark / light backgrounds |
| `brainstack-apilado-dark.svg` / `-light.svg` | Stacked logo (avatars, splash screens) |
| `brainstack-isotipo-dark.svg` / `-light.svg` | The mark alone |
| `brainstack-isotipo-currentcolor.svg` | The mark in one ink that follows CSS `color` |
| `social-preview.png` | GitHub social preview (1280×640) |

- Accent `#7c5cff`. Ink `#ededed` on dark backgrounds, `#0a0a0a` on light ones.
- Leave one layer of clear space around the logo. The smallest mark is 24 px.
- The mark is drawn on a 48-unit grid, so it stays sharp at 16, 32 and 48 px.
